# 🌊 Flood Risk Classifier

## Overview

The Flood Risk Classifier is a machine learning application that predicts flood risk levels using environmental, geographical, and infrastructure-related factors.

## Features

- Flood Risk Prediction
- Interactive Streamlit Dashboard
- Feature Importance Visualization
- Random Forest Machine Learning Model

## Dataset

- 50,000 records
- 20 flood-related features
- Target variable: Flood Probability

## Machine Learning Workflow

1. Data Collection
2. Data Preprocessing
3. Risk Classification
4. Random Forest Training
5. Model Evaluation
6. Deployment with Streamlit

## Technologies Used

- Python
- Pandas
- Scikit-Learn
- Streamlit
- Matplotlib
- Joblib

## Installation

```bash
pip install -r requirements.txt
```

## Train Model

```bash
python src/train.py
```

## Run Application

```bash
streamlit run app.py
```
